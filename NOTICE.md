# Attribution and reuse

MAT is a project-specific multi-agent research prototype maintained by Ewan Su
([Syx403](https://github.com/Syx403)). It uses MetaGPT's agent framework and external
libraries and services; those are not presented as original MAT implementations.

The repository retains introductory MetaGPT experiments, custom tool examples,
project code, historical notes, and generated reports. Source comments and Git
history preserve the existing development and AI-assistance attribution.

External software keeps its own license. Financial documents, market data, news,
and model outputs have their own provenance and applicable terms. Availability of
a report in this repository does not grant rights to all underlying source material.

No project-wide open-source license has been selected. The public repository is
available for inspection; it should not be treated as a blanket license grant for
the complete collection or third-party materials.
